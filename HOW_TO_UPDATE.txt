MOLLY’S INTERNET — QUICK GUIDE

UPLOAD THE CONTENTS OF THIS ZIP TO THE ROOT OF YOUR GITHUB PAGES REPOSITORY.
Keep index.html, the five other .html files, style.css, site.js, assets/, and content/ together.
The main homepage design and photo files are preserved.

HOW TO POST WITHOUT TOUCHING PAGE DESIGN
- Daily journal: edit content/timeline.json
- Photos: upload image to assets/ and edit content/photos.json
- Rabbit holes: edit content/rabbit-holes.json
- Projects: edit content/projects.json
- Year review: edit content/year-in-review.json

On GitHub: open a JSON file > pencil icon > add an entry > Commit changes.
Use double quotes around keys and values; separate entries with commas.
Put NEW entries inside the square brackets [ ... ]; each entry is inside { ... }.
Do NOT leave a trailing comma after the final entry.
For image names in JSON, use just the filename, e.g. "photo": "october20.jpg".
The actual file must be uploaded to assets/october20.jpg.

Homepage daily status and RECENTLY box are still edited directly in index.html.
All five homepage magazine tiles and the top navigation now link to real pages.

TEST: Open the site through its GitHub Pages URL. JSON loading may not work
when you double-click an HTML file on your computer due to browser security.

PRIVACY: Everything in this public repository and site is publicly accessible.
Avoid posting private addresses, personal account details, or sensitive journal entries.
